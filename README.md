# AGES Frontend Study Group

Repository for projects, exercises, and experiments developed during the **8th edition of the AGES Study Group**, in partnership with **Preto no Branco**, at PUCRS.

This repository documents my progress throughout the **Frontend Development** track, covering fundamental web technologies and modern frontend development practices.

## About the Study Group

The study group is a practical program focused on developing skills through hands-on projects and activities inspired by real-world software development.

**Institution:** PUCRS — AGES  
**Partner:** Preto no Branco  
**Track:** Frontend Development  
**Period:** August – September 2026

## Topics

Throughout the program, the following topics will be covered:

- Introduction to web development
- HTML, CSS, and JavaScript
- Interface creation and reproduction
- Responsive web design
- Application componentization
- React fundamentals
- API integration
- Frontend organization and best practices
- AI-assisted development
